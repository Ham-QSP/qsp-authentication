# Security Policy

`qsp-authentication` is an OAuth2 authorization server. A vulnerability here can
compromise every application that relies on it for authentication, so security
reports are treated with priority.

## Supported versions

Only the latest released version receives security fixes. Older tags are not
patched — upgrade before reporting an issue against an outdated release.

| Version | Supported |
|---------|-----------|
| latest release | Yes |
| older releases | No |

## Reporting a vulnerability

**Do not open a public issue for a security vulnerability.**

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/Ham-QSP/qsp-authentication/security/advisories/new).
This creates a private advisory visible only to the maintainers.

Please include:

- the affected version or commit,
- a description of the vulnerability and its impact,
- steps to reproduce, and a proof of concept if you have one,
- any suggested fix or mitigation.

You can expect an initial response within 7 days. Once a fix is available we
will publish a security advisory and credit you, unless you prefer to remain
anonymous.

## Scope

In scope: the authorization server itself — token issuance and validation,
the refresh token flow for public clients, client authentication, the user
management API, CORS and security filter chain configuration, and the published
Docker image.

Out of scope: vulnerabilities that require an already-compromised host or
database, findings against default development credentials in `application.yaml`
(these are local defaults only, never intended for deployment), and reports
generated by automated scanners without a demonstrated impact.

## Security practices in this repository

- Dependencies are updated weekly by Dependabot and scanned for known
  vulnerabilities in CI.
- Static analysis runs on every pull request; results are published to the
  repository's Security tab.
- The published container image is scanned before it is pushed.
- Secrets are never committed; `*.env` files are git-ignored and push
  protection is enabled on the repository.
